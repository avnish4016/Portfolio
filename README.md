## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation

1. Clone this repository:
```bash
git clone https://github.com/avnish4016/portfolio.git
cd portfolio
```

2. Open `index.html` in your browser to view the site locally

### Deployment

#### Option 1: GitHub Pages (Free & Easy)
1. Go to repository Settings
2. Under "Pages", select main branch as source
3. Your site will be live at `https://avnish4016.github.io/portfolio`

#### Option 2: Netlify (Free)
1. Visit https://netlify.com
2. Connect your GitHub repository
3. Click Deploy
4. Your site will be live with a custom domain option

#### Option 3: Vercel (Free)
1. Visit https://vercel.com
2. Import your repository
3. Click Deploy
4. Your site will be live instantly

## 📝 Customization

### Update Personal Information

Edit `index.html` and update:
- Name and email in footer
- Phone number in contact section
- Location in about section
- Social media links

### Add Your Projects

In the Portfolio Section, replace placeholder images:
```html
<img src="your-image-url" alt="Project Name">
```

### Customize Colors

Edit color variables in `styles.css`:
```css
:root {
    --accent-color: #ff6b6b;  /* Change this to your color */
}
```
